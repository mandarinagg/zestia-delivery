# Contribuir

1. Tomá un issue del milestone actual (o creá uno con la plantilla correspondiente).
2. Creá una rama: `feat/<issue>-descripcion`, `fix/…`, `docs/…`, `chore/…`.
3. Commits con [Conventional Commits](https://www.conventionalcommits.org/es/): `feat(orders): crear pedido manual`.
4. Abrí un PR con la plantilla, enlazando `Closes #N`.
5. Cumplí la [Definition of Done](docs/WORKING_AGREEMENT.md#definition-of-done).

Reglas clave: nada de secretos ni datos personales reales en el repo (es público), tests de aislamiento tenant en endpoints nuevos, docs actualizadas en el mismo PR.
