# Política de seguridad

Si encontrás una vulnerabilidad, **no abras un issue público**. Reportala de forma privada mediante [GitHub Security Advisories](https://github.com/mandarinagg/zestia-delivery/security/advisories/new) de este repositorio.

Respondemos dentro de 5 días hábiles. Detalles del modelo de seguridad del producto: [`docs/SECURITY.md`](docs/SECURITY.md).
